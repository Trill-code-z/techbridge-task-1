Program 01

Web Development

Designing and building websites and web applications

This track is for anyone who wants to create the interfaces and applications people use every day. You will learn how the web works end to end from structure and design to interactivity and deployment through practical projects you can put in a portfolio.

Best if you

Enjoy creating products people can see and use, like visual problem solving, and want to ship pages and apps you can demo to employers.

Skills you will develop
HTML and CSS JavaScript Responsive design React fundamentals Node.js basics Git and deployment Building web apps
What you will be able to do
  • Structure and style clean, responsive web pages
  • Add interactivity with modern JavaScript
  • Build component based interfaces with React
  • Connect basic backend logic and deploy a live project
  • Use Git to manage and share your work
Specific project examples
Portfolio Personal developer portfolio with project gallery, about section, and contact form
Business site Multi page company website with responsive layout and mobile navigation
Web app Task tracker or notes app with add, edit, delete, and local storage
Dashboard UI Admin style dashboard with cards, charts layout, and filter controls
API project Weather or news client that fetches live data and displays it cleanly
Deployed app Live project hosted on GitHub Pages or a free cloud host with a public URL
Apply for Web Development

Build for the web

From first layout to deployed app you learn by shipping real projects.

Program 02

Data Analytics

Working with data and extracting insights

This track is for learners who want to turn raw data into clear decisions. You will practice collecting, cleaning, analyzing, and visualizing data so you can tell a story with numbers the skill set organizations need for reporting, product decisions, and growth.

Best if you

Like finding patterns, answering questions with evidence, and turning spreadsheets or datasets into charts and recommendations others can act on.

Skills you will develop
Python for data SQL Data cleaning Statistics basics Data visualization Dashboards Insight storytelling
What you will be able to do
  • Clean and prepare messy real world datasets
  • Query data with SQL and analyze it with Python
  • Apply basic statistics to support your conclusions
  • Build clear charts and simple dashboards
  • Explain insights in plain language for decision makers
Specific project examples
Sales analysis Clean a sales CSV, find top products and trends, then present findings in charts
Customer insights Segment users by behavior or location and recommend next actions
SQL case study Write queries to answer business questions from a sample database
Dashboard Build a simple dashboard of KPIs with filters for date or category
Survey deep dive Analyze survey responses, visualize patterns, and summarize key takeaways
Insight report Turn a messy dataset into a short report with charts and plain language conclusions
Apply for Data Analytics

Turn data into decisions

Learn to clean, analyze, and communicate insights that drive real outcomes.
