Task roadmap

The 8-task internship path

Follow the timeline from Day 1 to Day 26. Each card shows when the task starts, what you will do, and how challenging it is.

01
Day 1 Beginner Available

Environment setup and first page

Install your tools, create your project folder, and publish a simple static HTML page. Confirm that you can open, edit, and view your work in the browser.

Focus: Editor setup, folder structure, basic HTML document, viewing locally
02
Day 4 Beginner Upcoming

Semantic HTML structure

Build a multi-section page using proper semantic tags (header, nav, main, section, footer). Structure content so it is clear for users and accessible for browsers.

Focus: Semantic markup, headings hierarchy, lists, links, images with alt text
03
Day 8 Beginner → Intermediate Upcoming

Styling with CSS

Apply layout and visual design with CSS. Control typography, color, spacing, and simple layout so your page looks intentional and readable.

Focus: Selectors, box model, fonts, colors, Flexbox basics
04
Day 11 Intermediate Upcoming

Responsive layouts

Make your layout adapt to phone, tablet, and desktop. Use media queries and flexible units so the same page works cleanly across screen sizes.

Focus: Media queries, fluid widths, mobile-first adjustments, navigation on small screens
05
Day 15 Intermediate Upcoming

JavaScript interactivity

Add behavior with JavaScript: respond to clicks, update the page without a full reload, and validate a simple form or toggle UI elements.

Focus: DOM selection, events, simple state changes, form feedback
06
Day 19 Intermediate → Advanced Upcoming

Interactive mini application

Combine HTML, CSS, and JavaScript into a small app (for example a task list or notes tool) with add, edit, and remove flows that feel usable.

Focus: Multi-step UI logic, local data storage, clearer component structure
07
Day 22 Intermediate → Advanced Upcoming

Working with APIs

Fetch live data from a public API and display it in your interface. Handle loading and error states so the experience stays understandable.

Focus: fetch requests, JSON, rendering results, basic error handling
08
Day 26 Capstone Upcoming

Portfolio project and deployment

Ship a polished project that showcases what you learned. Deploy it to a public URL and prepare a short write-up of your process and outcome — ready for your portfolio and recommendation review.

Focus: End-to-end project, deployment, README or summary, portfolio presentation

Progression: Day 1 → 4 → 8 → 11 → 15 → 19 → 22 → 26. Each step builds on the last.
